# 回望 · 投资决策分析工作台

课程选题三的 Web 工作台。功能包含登录隔离、日度价格导入与溯源、账户资金与交易、资产重放、价格分析、同资金流固定策略对照、决策日记、估值 CSV 导出。演示行情为确定性合成数据，不是真实股票行情。

## 启动

Node.js 22.13+。在此目录执行 `npm ci`、`npm run build`、`npm run dev`。本地 D1 需要先运行 `npm run db:generate` 并按序应用 `drizzle/*.sql`；部署由 Sites 自动应用迁移。托管站点使用 ChatGPT 登录，账户按登录用户隔离。

## 核心口径

- 账户从零余额起。资金、交易按 `effective_date, sequence, id` 顺序重放，历史修改必须通过后续全部事件的现金与持仓验证。
- 入金增加现金与净投入；出金相反。买卖影响现金与持仓，实际费用采用每笔记录值。
- 总资产 = 现金 + 每个持仓数量 × 最近已知收盘价；累计盈亏 = 总资产 − 累计净投入。缺报价时估值为空。
- 对照以同一资金流买入选定标的，按整数份额交易，余款保留；两条路径均以成交额 0.1% 的费用逐笔四舍五入到分。基准路径仅在入金当日或其后首个有价交易日买入，不在无资金流的日子反复交易；出金现金不足时当日卖出。
- 市场价格变化、最大回撤、近 20 个日收益年化波动是价格统计，不能当作账户收益率；未包含分红、税费、滑点。

手算验收：入金 $100；第 1 日买 5 份 @ $10、实际费用 $1；第 3 日卖 2 份 @ $11、实际费用 $1；三天收盘 $10/$12/$11，账户现金 $49/$49/$70，资产 $99/$109/$103，累计盈亏 −$1/$9/$3。统一费率实际期末资产 $104.93，固定规则 $108.91，差额 −$3.98。

运行 `node --experimental-strip-types --test tests/analysis.test.mjs` 检查上述口径、历史编辑限制和基准交易时间。

## 数据流程

1. 数据管理 → 导入合成演示行情（DEMO_A/B/C），或输入标的代码、名称、来源、价格口径后导入 `date,close` CSV。
2. 新建账户并录入入金，再录入交易（必须在该标的有当日报价，不能透支）；也可生成演示账户。
3. 市场分析查看标的指标、报价和来源。工作台核对资产曲线、净投入与持仓。
4. 规则对照选择基准标的；决策复盘记录交易前理由、预期和事后回顾；账户流水支持导出 CSV。

## Web API

`GET /api/workspace?account={id}&symbol={code}&from=YYYY-MM-DD&to=YYYY-MM-DD` 返回登录用户的账户、标的、报价、资金、交易、日记、资产序列和基准对照。

`POST /api/workspace` 使用 JSON 请求和 `action` 字段。支持 `account.create`、`flow.save`、`flow.delete`、`trade.save`、`trade.delete`、`note.save`、`note.delete`、`market.import`、`demo.seed`、`demo.account`、`demo.full`。`demo.full` 会为当前登录者创建或切换到独立的合成案例账户，并补齐三组虚构行情、出入金、七笔交易与三条笔记；再次调用不会重复创建。写入需登录，账户记录按 owner_id 隔离，非法账本写入返回 400。上传示例：

```json
{"action":"flow.save","accountId":1,"date":"2026-08-17","kind":"deposit","amountMinor":100000,"memo":"初始入金"}
```

## 与课程总方案的边界

当前交付为可运行的 Web 站点。它使用 Vinext / Cloudflare D1 / ChatGPT 登录，和三人开发指南预定的 **FastAPI + SQLite + 自有演示登录** 不是同一套服务，也没有构建 Java Android APK、MVVM/Room 离线缓存。安卓端不能直接把 ChatGPT 站点登录当成自身 API 鉴权。团队集成前，应由 A 按课程确定的 FastAPI 契约实现或迁移等价业务接口，并用上述手算样例核对；B 完成原生 App 与离线验收；C 核验导入价格的真实来源与口径。不能把本 Web 站点作为整个选题三已完成的证明。
