# 前端逐页、逐模块说明

本说明中的“参考”指 GitHub `web/`；“Android”指当前 `MainActivity.java`。模块是业务区块，不一定对应独立 Activity 或数据库表。

## 0. 通用界面
| 区块 | 是什么/为什么存在 | 操作与数据 | Android 当前情况 |
|---|---|---|---|
| 品牌头部 Header | 回望名称、数据覆盖日期、演示标识 | 日期来自 `asOf`，不等于当前实时行情日期 | 原生品牌头部和演示/连接模式文字 |
| 主导航 Navigation | 在业务页面间切换 | Web 为横向栏目；手机设计为底部主导航+二级页 | 目前是顶部滚动按钮，尚未按手机预览重构 |
| 账户选择器 | 每个账户有独立资金、交易和笔记 | `accounts`、`selected`；切换后重查 | 尚无多账户选择器 |
| 日期筛选 Filter | 改变观察区间 | Web `from/to`；不能删掉区间前交易，否则持仓错误 | 尚无日期筛选 UI |
| Banner / 状态反馈 | 告诉用户加载、成功、失败和演示边界 | 错误不可静默吞掉；保留用户输入供重试 | AlertDialog 与局部文字，需继续统一 |
| Editor / 模态表单 | 创建/修改账户、资金、交易、笔记、导入 | 保存先校验，失败保留表单；取消不写入 | 仅演示笔记新增，其他编辑器未迁移 |

## 1. 首页
**目的：**解释平台是什么，帮助用户选择下一步，不是把所有指标堆在首页。
- Hero 主视觉：“看见数据，也看见决定”，淡化曲线与渐变背景只是品牌插画，不是真实行情图。
- 数据摘要：标的数、报价条数、最新覆盖日期。来自 `instruments/prices/asOf`。
- 研究入口：市场研究、组合、规则对照、复盘；点击进入对应业务页。
- 演示案例入口：恢复合成案例，不代表导入了真实证券价格。
- Android：已有首页文案、Canvas 演示图与部分入口；品牌插画和正式底部导航待迁移。

## 2. 分析中心
**目的：**横向比较标的在相同观察口径下的历史收益和风险。
| 区块 | 应如何读 | 数据/算法 | 交互与边界 |
|---|---|---|---|
| 标准化价格图 | 比较不同绝对价格的走势 | 每个标的价格 ÷ 自身首个价格 ×100 | 日期筛选联动；不同起始日需要提示；不等于累计账户收益 |
| 收益—风险表 | 同时看收益、波动和下跌幅度 | `research.series` | 导出 CSV；样本不足显示不可计算而非 0 |
| 区间变化 | 期末价格相对期初价格的变化 | `(末价/首价−1)×100` | 不是未来收益预测 |
| 年化波动率 | 描述日收益离散程度 | 日简单收益样本标准差 ×√252×100 | 这是整个选定区间口径；不要与市场页近20日混用 |
| 最大回撤 | 区间峰值后曾跌了多少 | 每日价格/此前峰值−1 的最小值 | 负数；只含区间内峰值 |
| 上涨日占比 | 有多少日收益大于0 | 上涨收益日数/有效收益日数 | 价格样本数比收益样本数多1；0收益不算上涨 |
| 相关性矩阵 | 标的日收益是否同时变化 | Pearson，按共同收益日期对齐 | 少于3对或零方差不计算；显示共同样本数 |
| 回撤曲线 | 哪一段下跌更深、持续更久 | `points.drawdown` | 0%表示达到区间新高 |
| 风险收益散点图 | 横向波动，纵向区间变化 | `volatilityPct/returnPct` | 横纵指标时间尺度不同，不能当优化建议 |
| 月度热力表 | 观察月份间表现差异 | 月内收益连乘 | 首月可能不完整；明确月首与前一报价日衔接 |
| 研究结论 | 把数值翻译成可理解观察 | 动态最高区间变化等 | 仅描述当前样本；不输出“推荐买入” |

Android 已有标准化图、回撤图、指标文字和相关性；热力表、散点图、筛选及导出未迁移。手机 `/mobile` 用于排版参考，部分图表范围与指标口径有明确提示。

## 3. 市场研究
**目的：**单标的历史价格查询与溯源。
- 标的下拉：切换 `symbol`，显示名称、价格口径与来源。
- 最新收盘：是当前观察数据的末条，不保证今天最新。
- 指标：区间变化、价格回撤、近20日年化波动，样本不足不计算。
- 走势图：横轴日期，纵轴收盘价；Tooltip 提供具体值。
- 最近报价表：日期、代码、收盘价、来源。
- Android 当前：可选择标的并查看最近12条价格；尚无对应完整图表与日期控件。

## 4. 投资组合
**目的：**回答“我投入了多少、现在值多少、盈亏多少、持有什么”。
- 总资产：现金 + 持仓按可用收盘价估值；缺报价不能默认当0。
- 累计净投入：入金减出金，属于资金变化，不是收益。
- 累计盈亏：总资产减净投入，是金额，不能直接叫收益率。
- 现金余额：按事件顺序重放后的可用余额。
- 资产/净投入曲线：帮助分清市场表现和追加资金。
- 持仓列表：代码、名称、份额与估值；手机设计中有权重条，现金也应作为资产组成解释。
- 最近事件：资金或交易，能追溯到账本。
- Android 已有指标及份额列表；Web 曲线和手机权重条尚未完整移植。

## 5. 规则对照
**目的：**用相同资金进出比较不同历史决策路径，属于反事实历史分析。
- 实际路径：保留实际交易的成交价、份额及顺序，费用统一按0.1%重算。
- 固定规则：以选定标的为基准，入金后有价日尽量买整数份；出金现金不足时卖出。
- 差额：统一费率的实际期末资产减基准期末资产。
- 图表：两条资产路径；不是预测图。
- 规则说明：分红、税费、滑点等未覆盖因素应明确；基准不能满足出金时返回错误。
- Android：已有期末对照文字，尚无完整曲线和基准选择。

## 6. 交易账本
**目的：**管理可追溯的原始事件，组合估值依赖这里。
| 类型 | 必填信息 | 影响 |
|---|---|---|
| 入金/出金 | 日期、类型、金额；可选备注 | 现金与净投入 |
| 买入/卖出 | 日期、标的、方向、整数份额、单价、手续费 | 现金与持仓，不改变净投入 |

Web 的资金流水/记录交易按钮打开 Editor；每行可以编辑或删除。删除前确认，后端重放后续事件；若造成任意时点负现金或负持仓，拒绝修改。不是仅验证当前余额。
账户估值明细包含每日现金、净投入、资产、盈亏；可展开持仓、导出 CSV。
Android 当前账本只读，不能把 Web CRUD 已完成当成 App CRUD 已完成。

## 7. 决策复盘
**目的：**保留行动依据，防止事后改写当时的判断。
- 当时的理由：必填；事实、假设、为何行动。
- 当时的预期：可选；预期结果与风险。
- 关联交易：可选，只允许本账户交易；否则是独立笔记。
- 事后复盘：可选；有内容标记已复盘，否则待复盘。
- 补录：笔记创建日期晚于关联交易日期时标记；不是等同于已复盘。
- Web：搜索、新增、编辑、删除。Android：显示已有记录、演示新增；编辑/删除未迁移。

## 8. 模型实验
**目的：**展示配置→按时间划分→训练状态→评估→实验记录的研究流程。
- 任务：下一报价日方向分类，标签是次日是否高于当日。最后一条报价无标签，应剔除。
- 配置：选择模型、特征；前端 UI 选择本身不等于模型已训练。
- 特征：历史收益、滚动波动、均线偏离等；只能取当日及以前信息。
- 时间划分：训练60%、验证20%、测试20%是当前演示示意，真实响应要给出日期和数量。
- 状态：Web 模拟运行/取消/成功/失败重试；正式接口应提供任务ID、进度和错误。
- 固定样例：TP18、TN14、FP8、FN10，总50条。Accuracy64%；Precision69.23%；Recall64.29%；F1 66.67%。始终预测上涨基线56%。
- 预测明细：真实类别、预测类别、概率、正确/错误；概率是模拟值，不能叫准确率。
- 实验记录：保留配置、时间、模型版本、数据版本；当前 Web 记录为组件内存，离开模块可能重置。
- Android：配置、模拟运行及固定指标；真实训练、历史持久化、完整预测明细未完成。

## 9. AI 研究
**目的：**解释已有数据和指标，帮助用户提出更好的研究问题。
- 上下文：账户、标的、日期范围、数据版本；后端应按授权重新查数据，不信任客户端任意账户ID。
- 快捷提问：收益风险、组合集中度、最近交易复盘。
- 回答：应区分计算结果、模型解释和不确定性；来源可追溯。
- Web 当前：预填模拟摘要，发送后按模板模拟逐段输出；停止、清空、失败重试，不调用 DeepSeek。
- Android 当前：延迟显示模板回答，无真实 SSE。
- 真正集成：Android/Web → 自有后端 → 模型服务。密钥不能放 App/前端；服务商 base_url、准确 model ID 仍待确认。

## 10. 数据来源/管理
**目的：**查看样本是否足够、价格口径是否混用、能否追溯。
- 数据目录：代码、名称、source、price_type、覆盖日期、记录数、synthetic/imported。
- CSV：每行 `date,close`，2—1000条；价格美元，至多两位小数；日期真实有效且唯一。
- 导入弹窗：选择文件或粘贴内容，填写名称/来源/口径；保存校验失败应指出问题。
- source 是用户填写，不等于平台已核验；价格含分红/复权定义必须明确。
- Android：已有来源列表，文件选择与预览未实现。

## 11. 登录与连接设置
Web `/login` 是演示输入页，不是真实注册或鉴权。Android 设置页输入 HTTPS API 地址和用户 Access Token，读取 `/api/workspace`。当前没有登录/刷新token流程。早期 Web 后端使用 ChatGPT 认证 Header，不能直接当成 Android Bearer 服务。
